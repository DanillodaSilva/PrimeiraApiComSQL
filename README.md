🚗 API de Oficina Mecânica

API REST desenvolvida em Java com Spring Boot para gerenciamento de uma oficina mecânica.

🛠 Tecnologias
Java
Spring Boot
Spring Data JPA
Hibernate
MySQL
Maven
Lombok
Jakarta Validation
📋 Funcionalidades
👤 Cadastro de clientes
🚗 Cadastro de veículos
🔧 Cadastro de serviços
📄 Criação de ordens de serviço
🔗 Relacionamentos entre entidades
✅ Validação de dados
🚨 Tratamento de exceções
📚 Objetivo

Projeto desenvolvido para praticar conceitos de Java Backend, incluindo APIs REST, JPA/Hibernate, banco de dados SQL, DTOs e relacionamentos entre entidades.
